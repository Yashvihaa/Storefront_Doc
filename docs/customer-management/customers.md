# Customers

The **Customers List** stores the profiles of your registered customers. You can add, edit, view, activate or deactivate, and delete customer accounts.

---

## Customers List Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Type in the search box to find customers. The list updates as you type. |
| **Add New Customers** | Click **Add New Customers** to create a new customer account. |
| **View** | Click the **eye** icon to open the customer's details page. |
| **Edit** | Click the **Edit** icon to update the customer's name, mobile number, country or image. |
| **Delete** | Click the **Delete** icon and confirm to permanently remove the customer. |
| **Status** | Use the **Status** switch to activate or deactivate the customer. The current status is also shown as a badge. |
| **View Documentation** | Opens the help page for this screen in a new browser tab. |

The list shows the customer's **Image**, **Name**, **Email**, **Phone No.** and **Status**.

---

### Steps to Add a New Customer

Click **Add New Customers**, fill in the form and click **Submit**.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| Name | ✅ | Enter the customer's full name. |
| Email | ✅ | Enter a valid email address. |
| Mobile No. | ✅ | Digits only, at least 10 digits (maximum 10). |
| Password | ✅ | At least 8 characters, with an uppercase letter, a lowercase letter, a number and a special character. |
| Select Country | ✅ | Choose the customer's country from the dropdown. |
| Upload Image | - | Upload a profile image. Recommended aspect ratio: 500 x 500. |

:::note
When editing a customer, the **Email** cannot be changed and the **Password** field is not shown.
:::

---

## Customer Details

Click the **eye** icon on a customer to open their details page.

| Section | Description |
| ------- | ----------- |
| **Profile** | The customer's image and name. |
| **Details** | **Username**, **Email**, **Status** (**Active** or **Inactive**) and **Contact** number. |
| **Recent Search Data** | The customer's recent searches on the storefront, listed under **Search Value**. Shown only if the customer has searched. |

Click **Back** to return to the Customers List.
