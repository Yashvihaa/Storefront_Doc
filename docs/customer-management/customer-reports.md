# Customer Reports

The **Customer Reports** page lets you download customer data as an Excel file for a chosen report type and date range.

---

## Customer Reports Screen List

| Action | Description |
| ------ | ----------- |
| **Customer Reports** | Select the type of report to download. |
| **Date Range** | Select the start and end dates for the report. |
| **Download Excel** | Downloads the selected report as an Excel file. |
| **View Documentation** | Opens the help page for this screen in a new browser tab. |

---

### Steps to Download a Report

| Field | Required | Remarks |
| ----- | -------- | ------- |
| Customer Reports | ✅ | Choose the report type from the dropdown. |
| Date Range | ✅ | Pick a start and end date. Defaults to the last 8 months. |

Then click **Download Excel**.

---

### Report Types

| Report | Contents |
| ------ | -------- |
| **Customers** | Customer name, email, country code and phone number. |
| **Customers Subscribers** | Subscriber email and the date they subscribed. |
| **Customers Wishlist** | Wishlisted products (name, SKU, slug, descriptions) with the customer's name, email and phone number. |
| **Customers Cart** | Products in customers' carts with the customer's details and the product's name, SKU, image, size, length, metal, karat, metal tones and price. |
| **Top Selling Products** | Products with their order count, SKU, name and slug. |

:::note
If you click **Download Excel** without selecting a report, or if the report has no data for the selected dates, a message appears and no file is downloaded.
:::
