# Metals

The **Metal Master** page lists the metals used across products and configurators, such as Gold, Silver and Platinum. You cannot add, edit or delete metals here. You can only view them, search them and switch them on or off.

---

## Metal Master Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the **Search** box to find metals. The list updates about a second after you stop typing. Clear the box to show all metals again. |
| **Filter** | Click **Filter** to show or hide a filter box under each column heading. Filtering applies to the rows on the current page. |
| **Info** | Opens the **Metal Info** drawer, which shows the module's **Title** and **Description**. Both are required (**This Field is required**). Change them and click **Submit** to save, or click **Cancel** to close. Without **Edit** permission the fields and **Submit** are disabled. |
| **Status** | Shows whether the metal is **Active** or **Inactive**. |
| **Status Toggle** | Switch a metal on or off directly from the list. The change is saved immediately, without a confirmation box. |

The **View Documentation** button at the top right of the page opens this guide.

### Metal Master List Columns

| Column | Description |
| ------ | ----------- |
| **Metal Name** | Name of the metal. |
| **Slug** | Web-friendly version of the name. |
| **Status** | An **Active** or **Inactive** badge, followed by the on/off switch. |

There is no **Action** column and no **Add** button on this page. Click a column heading to sort by it; the **Status** columns cannot be sorted. The newest records are shown first, 50 rows per page by default; use the page controls under the list to move between pages or to show 25, 50, 75 or 100 rows.

:::note
The status toggle is disabled for users without **Edit** permission.
:::

:::tip
Only active metals are offered when you add a [Metal Tone](./metal-tone.md). Switching a metal off therefore removes it from that list.
:::

## How Metals Are Used

| Where | How it uses metals |
| ----- | ------------------ |
| [Metal Tone](./metal-tone.md) | Each metal tone belongs to one metal. You pick the metal in **Select Metal** when you add the tone; only active metals are offered. |
| [Metal Karat](./metal-karat.md) | Karats can only be added for Gold. The **Select Metal** list on the karat form shows only the Gold metal. |
| [Metal Rate Settings](../../../settings/metal-rate-setting.md) | Metal rates are not set on this page. The **Gold**, **Silver** and **Platinum** buttons on Metal Rate Settings come from this metal list, and that page is where you set each metal's rate and margin. For Gold, the final rates are shown per karat. |
