# Metal Karat

The **Karat Master** page manages the gold karats offered for your products, for example 10K, 14K and 18K, along with the gold percentage of each karat.

---

## Karat Master Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find karats. The list updates about a second after you stop typing. Clear the box to show all karats again. |
| **Info** | Opens the **Metal Karat Info** drawer, which shows the module's **Title** and **Description**. Change them and click **Submit** to save, or click **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Karat** | Click the **Add Karat** button to create a new karat. |
| **Edit** | Click the **Edit** icon to change a karat's value, gold percentage or image. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a karat. Click **NO** to keep it. |
| **Status** | Shows whether the karat is **Active** or **Inactive**. |
| **Status Toggle** | Switch a karat on or off directly from the list. |

The list shows the **Image**, **Carat**, **Slug**, **Gold Calculate Rate** and **Status** of each karat, and can be sorted and paged. **Gold Calculate Rate** is the gold percentage of the karat, shown with two decimals.

:::note
The **Add Karat** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The drawer fields and the **SUBMIT** button are disabled without **Edit** permission, including when you add a new karat.
:::

---

### Steps to Add a New Karat

Click **Add Karat**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Karat** | ✅ | Karat value. Whole numbers only, for example 14 or 18. |
| **Select Metal** | ✅ | Only the Gold metal is offered. Shows **Please select metal** if left empty. |
| **Gold Percentage** | - | Percentage of pure gold in this karat, for example 58.3 for 14K. Cannot be more than 100. |
| **Upload Image** | - | Drop an image or click to upload. Accepts .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif files up to 20 MB. Recommended aspect ratio: 500 x 500. |

:::tip
Karats apply only to Gold. The Gold rates on [Metal Rate Settings](../../../settings/metal-rate-setting.md) are shown per karat.
:::
