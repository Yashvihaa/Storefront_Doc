# Metal Tone

The **Metal Tone** page manages the tones shown for each metal, for example Rose Gold, Yellow Gold and White Gold for Gold. Each tone belongs to one metal from [Metals](./metals.md).

---

## Metal Tone Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find metal tones. The list updates about a second after you stop typing. Clear the box to show all tones again. |
| **Info** | Opens the **Metal Tone Info** drawer, which shows the module's **Title** and **Description**. Change them and click **Submit** to save, or click **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Metal Tone** | Click the **Add Metal Tone** button to create a new tone. |
| **Edit** | Click the **Edit** icon to change a tone's name, metal or image. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a tone. Click **NO** to keep it. |
| **Status** | Shows whether the tone is **Active** or **Inactive**. |
| **Status Toggle** | Switch a tone on or off directly from the list. |

The list shows the **Image**, **Metal Tone**, **Slug**, **Sort Code** and **Status** of each tone, and can be sorted and paged.

:::note
The **Add Metal Tone** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The drawer fields and the **SUBMIT** button are disabled without **Edit** permission, including when you add a new tone.
:::

---

### Steps to Add a New Metal Tone

Click **Add Metal Tone**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Metal Tone Name** | ✅ | Name of the tone, for example Rose Gold. |
| **Sort Code** | ✅ | Short code for the tone, for example RG. Cannot be changed after the tone is created. |
| **Select Metal** | ✅ | The metal this tone belongs to. |
| **Upload Image** | ✅ | Drop an image or click to upload. Accepts .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif files up to 20 MB. Recommended aspect ratio: 50 x 50. |
