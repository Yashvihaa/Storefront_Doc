# Setting Style

The **Setting Style** page manages the setting styles available for your products, for example Channel, U Micro and Prong.

---

## Setting Style Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find setting styles. The list updates about a second after you stop typing. Clear the box to show all styles again. |
| **Info** | Opens the **Setting Type Info** drawer, which shows the module's **Title** and **Description**. Change them and click **Submit** to save, or click **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Setting Style** | Click the **Add Setting Style** button to create a new style. |
| **Edit** | Click the **Edit** icon to change a style's details. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a style. Click **NO** to keep it. |
| **Status** | Shows whether the style is **Active** or **Inactive**. |
| **Status Toggle** | Switch a style on or off directly from the list. |

The list shows the **Image**, **Setting Style Value**, **Slug**, **Sort Code** and **Status** of each style, and can be sorted and paged.

:::note
The **Add Setting Style** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The text fields and the **SUBMIT** button in the drawer are disabled without **Edit** permission, including when you add a new style.
:::

---

### Steps to Add a New Setting Style

Click **Add Setting Style**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Setting Style Name** | ✅ | Name of the style, for example Prong. |
| **Sort Code** | ✅ | Short code for the style. |
| **Upload Image** | ✅ | Drop an image or click to upload. Accepts .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif files up to 20 MB. Recommended aspect ratio: 100 x 100. |
