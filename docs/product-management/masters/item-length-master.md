# Item Length

The **Item Length** page manages the item lengths available for your products, such as bracelet lengths.

---

## Item Length Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find item lengths. The list updates about one second after you stop typing; clear the box to show all item lengths again. |
| **Info** | Opens the **Item Length Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Item Length** | Click the **Add Item Length** button to create a new item length. |
| **Edit** | Click the **Edit** icon to change an item length or its sort order. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove an item length. Click **NO** to keep it. |
| **Status** | Shows whether the item length is **Active** or **Inactive**. |
| **Status Toggle** | Switch an item length on or off directly from the list. |

The list shows the **Item Length**, **Slug**, **Sort Order** and **Status** of each record, and can be sorted and paged.

:::note
Without **Add** permission the **Add Item Length** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Item Length

Click **Add Item Length**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Sort Order** | - | Number that sets the display order. |
| **Item Length** | ✅ | The length value. If it is missing, the message **Item Length is required** is shown. |

:::note
The **Item Length** field and the **SUBMIT** button need **Edit** permission, even when you add a new item length.
:::
