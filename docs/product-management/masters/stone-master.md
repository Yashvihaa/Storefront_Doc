# Stone Master

The **Stone Master** manages the stones and gemstones used in your products. Each stone is marked as either a diamond or a gemstone.

---

## Stone Master Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find stones. The list updates about a second after you stop typing. Clear the box to show all stones again. |
| **Info** | Opens the **Stone Info** drawer, which shows the module's **Title** and **Description**. Change them and click **Submit** to save, or click **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Stone Master** | Click the **Add Stone Master** button to create a new stone. |
| **Edit** | Click the **Edit** icon to change a stone's details. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a stone. Click **NO** to keep it. |
| **Status** | Shows whether the stone is **Active** or **Inactive**. |
| **Status Toggle** | Switch a stone on or off directly from the list. |

The list shows the **Image**, **Name**, **Slug**, **Sort Code** and **Status** of each stone, and can be sorted and paged.

:::note
The **Add Stone Master** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The drawer fields and the **SUBMIT** button are disabled without **Edit** permission, including when you add a new stone.
:::

---

### Steps to Add a New Stone

Click **Add Stone Master**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Stone Name** | ✅ | Name of the stone, for example Diamond or Ruby. |
| **Sort Code** | ✅ | Short code for the stone. |
| **Stone Type** | ✅ | **Diamond** or **Gemstone**. |
| **Upload Image** | ✅ | Drop an image or click to upload. Accepts .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif files up to 20 MB. Recommended aspect ratio: 100 x 100. |

:::tip
The **Stone Type** field here is a fixed choice between **Diamond** and **Gemstone**. It is not linked to the [Stone Type](./stone-type.md) master.
:::
