# Color

The **Color** page manages the diamond colors available for your products, for example D, E or F. Colors are also used as the **Color** choice in the [Diamond Group Master](../diamond-group-master.md) to price diamonds.

---

## Color Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the **Search** box to find colors. The list updates about one second after you stop typing; clear the box to show all colors again. |
| **Filter** | Click **Filter** to show or hide a filter box under each column heading. Filtering applies to the rows on the current page. |
| **Info** | Opens the **Color Info** drawer showing this module's **Title** and **Description**. Both are required (**This Field is required**). Click **Submit** to save or **Cancel** to close. Without **Edit** permission the fields and **Submit** are disabled. |
| **Add Color** | Click the **Add Color** button to open the **Add Color** drawer and create a new color. |
| **Edit** | Click the **Edit** icon to open the **Edit Color** drawer and change a color's name. |
| **Delete** | Click the **Delete** icon. A box titled **Are you Sure?** asks you to confirm; click **YES** to delete the color or **NO** to keep it. If the deletion is not allowed, an error message is shown and the color stays in the list. |
| **Status** | Shows whether the color is **Active** or **Inactive**. |
| **Status Toggle** | Switch a color on or off directly from the list. The change is saved immediately, without a confirmation box. |

The **View Documentation** button at the top right of the page opens this guide.

### Color List Columns

| Column | Description |
| ------ | ----------- |
| **Action** | The **Edit** and **Delete** icons. |
| **Name** | Name of the color. |
| **Slug** | Web-friendly version of the name. It is shown for reference and is not a field on the form. |
| **Status** | An **Active** or **Inactive** badge, followed by the on/off switch. |

Click a column heading to sort by it. The **Action** and **Status** columns cannot be sorted. The newest colors are shown first, 50 rows per page by default; use the page controls under the list to move between pages or to show 25, 50, 75 or 100 rows.

:::note
Without **Add** permission the **Add Color** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Color

Click **Add Color**, fill in the field below and click **Add Color** at the bottom of the drawer. When editing, the same button reads **Save Color**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Color Name** | ✅ | Name of the diamond color, for example D, E or F. If it is empty, the message **This Field is required** is shown. |

The drawer closes and the list refreshes once the color is saved. If saving fails, a red message appears and the drawer stays open.

:::note
The **Color Name** field and the **Add Color** / **Save Color** button need **Edit** permission, even when you add a new color.
:::
