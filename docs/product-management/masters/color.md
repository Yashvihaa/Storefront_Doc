# Color

The **Color** page manages the diamond colors available for your products. Colors are also used in the [Diamond Group Master](../diamond-group-master.md) to price diamonds.

---

## Color Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find colors. The list updates about one second after you stop typing; clear the box to show all colors again. |
| **Info** | Opens the **Color Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Color** | Click the **Add Color** button to create a new color. |
| **Edit** | Click the **Edit** icon to change a color's name. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a color. Click **NO** to keep it. |
| **Status** | Shows whether the color is **Active** or **Inactive**. |
| **Status Toggle** | Switch a color on or off directly from the list. |

The list shows the **Name**, **Slug** and **Status** of each color, and can be sorted and paged.

:::note
Without **Add** permission the **Add Color** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Color

Click **Add Color**, fill in the field below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Color Name** | ✅ | Name of the diamond color, for example D, E or F. |

:::note
The **Color Name** field and the **SUBMIT** button need **Edit** permission, even when you add a new color.
:::
