# Carat Size

The **Carat Size** page manages the carat sizes available for your products. Carat sizes are also used in the [Diamond Group Master](../diamond-group-master.md) to price stones.

---

## Carat Size Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find carat sizes. The list updates about one second after you stop typing; clear the box to show all carat sizes again. |
| **Info** | Opens the **Carat Size Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Carat Size** | Click the **Add Carat Size** button to create a new carat size. |
| **Edit** | Click the **Edit** icon to change a carat size's value or image. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a carat size. Click **NO** to keep it. |
| **Status** | Shows whether the carat size is **Active** or **Inactive**. |
| **Status Toggle** | Switch a carat size on or off directly from the list. |

The list shows the **Image**, **Value**, **Slug**, **Sort Code** and **Status** of each carat size, and can be sorted and paged. Hover over an image to see a larger preview.

:::note
Without **Add** permission the **Add Carat Size** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Carat Size

Click **Add Carat Size**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Value** | ✅ | Carat size as a positive number, for example 0.50 or 1.25. Up to 10 decimal places are allowed. Otherwise the message **The size must be a positive number** is shown. |
| **Sort Code** | - | Shown only when editing, and read-only. |
| **Upload Image** | - | Image for the carat size. The form suggests an aspect ratio of 100 x 100. |

To add the image, drop a file on the upload area or click it to choose one. Allowed types are .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif, up to 20 MB. Click the **x** on the preview to remove the image.

:::note
**Upload Image** is marked with a red asterisk, but the form does not check it. You can save a carat size without an image.
:::

:::note
The fields and the **SUBMIT** button need **Edit** permission, even when you add a new carat size.
:::
