# Head

The **Head** page manages the head styles used in ring products. The head, also called the crown, is the part of the setting that holds the center stone in place. Each head has a name, a sort code and an image.

---

## Head Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the **Search** box to find heads. The list updates about one second after you stop typing; clear the box to show all heads again. |
| **Filter** | Click **Filter** to show or hide a filter box under each column heading. Filtering applies to the rows on the current page. |
| **Info** | Opens the **Head Info** drawer showing this module's **Title** and **Description**. Both are required (**This Field is required**). Click **Submit** to save or **Cancel** to close. Without **Edit** permission the fields and **Submit** are disabled. |
| **Add Head** | Click the **Add Head** button to open the **Add Head** drawer and create a new head. |
| **Edit** | Click the **Edit** icon to open the **Edit Head** drawer with the current name, sort code and image. |
| **Delete** | Click the **Delete** icon. A box titled **Are you Sure?** asks you to confirm; click **YES** to delete the head or **NO** to keep it. If the deletion is not allowed, an error message is shown and the head stays in the list. |
| **Status** | Shows whether the head is **Active** or **Inactive**. |
| **Status Toggle** | Switch a head on or off directly from the list. The change is saved immediately, without a confirmation box. |

The **View Documentation** button at the top right of the page opens this guide.

### Head List Columns

| Column | Description |
| ------ | ----------- |
| **Action** | The **Edit** and **Delete** icons. |
| **Image** | Picture of the head. Hover over it to see a larger preview. |
| **Value** | Name of the head. |
| **Slug** | Web-friendly version of the name. It is shown for reference and is not a field on the form. |
| **Sort Code** | The code you entered, for example HD01. |
| **Status** | An **Active** or **Inactive** badge, followed by the on/off switch. |

Click a column heading to sort by it. The **Action**, **Image** and **Status** columns cannot be sorted. The newest heads are shown first, 50 rows per page by default; use the page controls under the list to move between pages or to show 25, 50, 75 or 100 rows.

:::note
Without **Add** permission the **Add Head** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

### Steps to Add a New Head

Click **Add Head**, fill in the fields below and click **Add Head** at the bottom of the drawer. When editing, the same button reads **Save Head**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Head Name** | ✅ | Name of the head style. If it is empty, the message **This Field is required** is shown. |
| **Sort Code** | ✅ | Sort code of the head, for example HD01. If it is empty, the message **This Field is required** is shown. |
| **Upload Image** | ✅ | Image of the head style. The form suggests an aspect ratio of 100 x 100. If it is missing, the message **Image is required** is shown. |

To add the image, drop a file on the upload area or click it to choose one. Only one image can be used. Allowed types are .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif, up to 20 MB. A file of another type shows **Only allowed image file types can be uploaded** followed by the allowed list, and a rejected or oversized file shows **You can only upload files with a maximum size of 20 MB.** Click the **x** on the preview to remove the image; if you remove it and do not choose another, **Please Upload Image** is shown and you cannot save.

The drawer closes and the list refreshes once the head is saved. If saving fails, a red message appears and the drawer stays open so you can correct the entry.

:::note
The fields and the **Add Head** / **Save Head** button need **Edit** permission, even when you add a new head.
:::
