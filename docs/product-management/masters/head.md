# Head

The **Head** page manages the head styles used in ring products. The head, also called the crown, is the part of the setting that holds the center stone in place.

---

## Head Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find heads. The list updates about one second after you stop typing; clear the box to show all heads again. |
| **Info** | Opens the **Head Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Head** | Click the **Add Head** button to create a new head. |
| **Edit** | Click the **Edit** icon to change a head. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a head. Click **NO** to keep it. |
| **Status** | Shows whether the head is **Active** or **Inactive**. |
| **Status Toggle** | Switch a head on or off directly from the list. |

The list shows the **Image**, **Value** (the head name), **Slug**, **Sort Code** and **Status** of each head, and can be sorted and paged. Hover over an image to see a larger preview.

:::note
Without **Add** permission the **Add Head** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Head

Click **Add Head**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Head Name** | ✅ | Name of the head style. |
| **Sort Code** | ✅ | Sort code of the head, for example HD01. |
| **Upload Image** | ✅ | Image of the head style. The form suggests an aspect ratio of 100 x 100. If it is missing, the message **Image is required** is shown. |

To add the image, drop a file on the upload area or click it to choose one. Allowed types are .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif, up to 20 MB. Click the **x** on the preview to remove the image.

:::note
The fields and the **SUBMIT** button need **Edit** permission, even when you add a new head.
:::
