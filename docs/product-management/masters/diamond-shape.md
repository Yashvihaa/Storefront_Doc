# Diamond Shape

The **Diamond Shape** page manages the diamond shapes available for your products, such as Round, Oval, Princess or Marquise. Shapes are also used in the [Diamond Group Master](../diamond-group-master.md) to price stones.

---

## Diamond Shape Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find diamond shapes. The list updates about one second after you stop typing; clear the box to show all shapes again. |
| **Info** | Opens the **Diamond Shape Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Diamond Shape** | Click the **Add Diamond Shape** button to create a new shape. |
| **Edit** | Click the **Edit** icon to change a shape. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a shape. Click **NO** to keep it. |
| **Status** | Shows whether the shape is **Active** or **Inactive**. |
| **Status Toggle** | Switch a shape on or off directly from the list. |

The list shows the **Image**, **Name**, **Slug**, **Sort Code** and **Status** of each shape, and can be sorted and paged. Hover over an image to see a larger preview.

:::note
Without **Add** permission the **Add Diamond Shape** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Diamond Shape

Click **Add Diamond Shape**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Diamond Shape Name** | ✅ | Name of the shape, for example Round or Oval. |
| **Sort Code** | ✅ | Short code for the shape, for example RND or OVL. |
| **Upload Image** | ✅ | Image of the shape. The form suggests an aspect ratio of 100 x 100. If it is missing, the message **Image is required** is shown. |

To add the image, drop a file on the upload area or click it to choose one. Allowed types are .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif, up to 20 MB. Click the **x** on the preview to remove the image.

:::note
The **SUBMIT** button needs **Edit** permission, even when you add a new shape.
:::
