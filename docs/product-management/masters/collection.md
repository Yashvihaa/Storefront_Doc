# Collection

## Overview

Collections group products, for example into a seasonal or themed range.

:::note
The **Collection** master page is no longer part of the admin panel. There is no screen to search, add, edit, delete or switch collections on or off.
:::

---

## Data Displayed

There is no collection list to display. The only place collections appear is the **Collection Name** field of the product forms on [All Products](../all-products.md):

| Form | Field | Remarks |
| ---- | ----- | ------- |
| **Add Normal Product** | **Collection Name** | Select one or more collections. |
| **Add Variant Product** | **Collection Name** | Select one or more collections. |
| **Add Choose Settings Product** | **Collection Name** | Select one or more collections. |

---

## How It Works

The **Collection Name** field lists the collections already stored for your store. A product can be placed in more than one collection. Collections cannot be created or changed from the admin panel, so contact your administrator or support team if the list needs to change.

---

## Dependencies and Impact

### Modules It Depends On

None. There is no page that manages collections.

### Modules That Depend On It

| Module | How it uses collections |
| ------ | ----------------------- |
| [All Products](../all-products.md) | The product forms offer the **Collection Name** field. |

### What Changes If…

Nothing can be changed from the admin panel, so there is no effect to describe.

---

## Edge Cases / Notes

- **Not in the menu.** This page is kept for reference only. It is not listed in the sidebar.
- **Empty list.** If no collections are stored for your store, the **Collection Name** field has nothing to offer.
