# Diamond Cut

The **Diamond Cut** page manages the diamond cut grades available for your products, such as Good, Very Good or Excellent. Cut grades are also used as the **Cut** choice in the [Diamond Group Master](../diamond-group-master.md) to price stones.

---

## Diamond Cut Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the **Search** box to find cut grades. The list updates about one second after you stop typing; clear the box to show all cut grades again. |
| **Filter** | Click **Filter** to show or hide a filter box under each column heading. Filtering applies to the rows on the current page. |
| **Info** | Opens the **Cut Info** drawer showing this module's **Title** and **Description**. Both are required (**This Field is required**). Click **Submit** to save or **Cancel** to close. Without **Edit** permission the fields and **Submit** are disabled. |
| **Add Diamond Cut** | Click the **Add Diamond Cut** button to open the **Add Diamond Cut** drawer and create a new cut grade. |
| **Edit** | Click the **Edit** icon to open the **Edit Diamond Cut** drawer and change a cut grade's value. |
| **Delete** | Click the **Delete** icon. A box titled **Are you Sure?** asks you to confirm; click **YES** to delete the cut grade or **NO** to keep it. If the deletion is not allowed, an error message is shown and the grade stays in the list. |
| **Status** | Shows whether the cut grade is **Active** or **Inactive**. |
| **Status Toggle** | Switch a cut grade on or off directly from the list. The change is saved immediately, without a confirmation box. |

The **View Documentation** button at the top right of the page opens this guide.

### Diamond Cut List Columns

| Column | Description |
| ------ | ----------- |
| **Action** | The **Edit** and **Delete** icons. |
| **Cut Value** | Name of the cut grade. |
| **Slug** | Web-friendly version of the name. It is shown for reference and is not a field on the form. |
| **Status** | An **Active** or **Inactive** badge, followed by the on/off switch. |

Click a column heading to sort by it. The **Action** and **Status** columns cannot be sorted. The newest cut grades are shown first, 50 rows per page by default; use the page controls under the list to move between pages or to show 25, 50, 75 or 100 rows.

:::note
Without **Add** permission the **Add Diamond Cut** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Diamond Cut

Click **Add Diamond Cut**, fill in the field below and click **Add Diamond Cut** at the bottom of the drawer. When editing, the same button reads **Save Diamond Cut**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Value** | ✅ | Name of the cut grade, for example Excellent. If it is empty, the message **This Field is required** is shown. |

The drawer closes and the list refreshes once the cut grade is saved. If saving fails, a red message appears and the drawer stays open.

:::note
The **Value** field and the **Add Diamond Cut** / **Save Diamond Cut** button need **Edit** permission, even when you add a new cut grade.
:::
