# Diamond Cut

The **Diamond Cut** page manages the diamond cut grades available for your products, such as Good, Very Good or Excellent. Cut grades are also used in the [Diamond Group Master](../diamond-group-master.md) to price stones.

---

## Diamond Cut Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find cut grades. The list updates about one second after you stop typing; clear the box to show all cut grades again. |
| **Info** | Opens the **Cut Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Diamond Cut** | Click the **Add Diamond Cut** button to create a new cut grade. |
| **Edit** | Click the **Edit** icon to change a cut grade's value. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a cut grade. Click **NO** to keep it. |
| **Status** | Shows whether the cut grade is **Active** or **Inactive**. |
| **Status Toggle** | Switch a cut grade on or off directly from the list. |

The list shows the **Cut Value**, **Slug** and **Status** of each cut grade, and can be sorted and paged.

:::note
Without **Add** permission the **Add Diamond Cut** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Diamond Cut

Click **Add Diamond Cut**, fill in the field below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Value** | ✅ | Name of the cut grade, for example Excellent. |

:::note
The **Value** field and the **SUBMIT** button need **Edit** permission, even when you add a new cut grade.
:::
