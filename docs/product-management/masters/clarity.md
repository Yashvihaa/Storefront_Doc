# Clarity

The **Clarity** page manages the diamond clarity grades available for your products. Clarity grades are also used in the [Diamond Group Master](../diamond-group-master.md) to price diamonds.

---

## Clarity Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find clarity grades. The list updates about one second after you stop typing; clear the box to show all clarity grades again. |
| **Info** | Opens the **Clarity Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Clarity** | Click the **Add Clarity** button to create a new clarity grade. |
| **Edit** | Click the **Edit** icon to change a clarity grade's name. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a clarity grade. Click **NO** to keep it. |
| **Status** | Shows whether the clarity grade is **Active** or **Inactive**. |
| **Status Toggle** | Switch a clarity grade on or off directly from the list. |

The list shows the **Name**, **Slug** and **Status** of each clarity grade, and can be sorted and paged.

:::note
Without **Add** permission the **Add Clarity** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Clarity

Click **Add Clarity**, fill in the field below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Clarity Name** | ✅ | Name of the clarity grade, for example VS1 or SI2. |

:::note
The **Clarity Name** field and the **SUBMIT** button need **Edit** permission, even when you add a new clarity grade.
:::
