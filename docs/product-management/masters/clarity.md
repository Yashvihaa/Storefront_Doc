# Clarity

The **Clarity** page manages the diamond clarity grades available for your products, for example VS1 or SI2. Clarity grades are also used as the **Clarity** choice in the [Diamond Group Master](../diamond-group-master.md) to price diamonds.

---

## Clarity Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the **Search** box to find clarity grades. The list updates about one second after you stop typing; clear the box to show all clarity grades again. |
| **Filter** | Click **Filter** to show or hide a filter box under each column heading. Filtering applies to the rows on the current page. |
| **Info** | Opens the **Clarity Info** drawer showing this module's **Title** and **Description**. Both are required (**This Field is required**). Click **Submit** to save or **Cancel** to close. Without **Edit** permission the fields and **Submit** are disabled. |
| **Add Clarity** | Click the **Add Clarity** button to open the **Add Clarity** drawer and create a new clarity grade. |
| **Edit** | Click the **Edit** icon to open the **Edit Clarity** drawer and change a clarity grade's name. |
| **Delete** | Click the **Delete** icon. A box titled **Are you Sure?** asks you to confirm; click **YES** to delete the clarity grade or **NO** to keep it. If the deletion is not allowed, an error message is shown and the grade stays in the list. |
| **Status** | Shows whether the clarity grade is **Active** or **Inactive**. |
| **Status Toggle** | Switch a clarity grade on or off directly from the list. The change is saved immediately, without a confirmation box. |

The **View Documentation** button at the top right of the page opens this guide.

### Clarity List Columns

| Column | Description |
| ------ | ----------- |
| **Action** | The **Edit** and **Delete** icons. |
| **Name** | Name of the clarity grade. |
| **Slug** | Web-friendly version of the name. It is shown for reference and is not a field on the form. |
| **Status** | An **Active** or **Inactive** badge, followed by the on/off switch. |

Click a column heading to sort by it. The **Action** and **Status** columns cannot be sorted. The newest clarity grades are shown first, 50 rows per page by default; use the page controls under the list to move between pages or to show 25, 50, 75 or 100 rows.

:::note
Without **Add** permission the **Add Clarity** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Clarity

Click **Add Clarity**, fill in the field below and click **Add Clarity** at the bottom of the drawer. When editing, the same button reads **Save Clarity**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Clarity Name** | ✅ | Name of the clarity grade, for example VS1 or SI2. If it is empty, the message **This Field is required** is shown. |

The drawer closes and the list refreshes once the grade is saved. If saving fails, a red message appears and the drawer stays open.

:::note
The **Clarity Name** field and the **Add Clarity** / **Save Clarity** button need **Edit** permission, even when you add a new clarity grade.
:::
