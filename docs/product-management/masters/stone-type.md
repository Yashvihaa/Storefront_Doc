# Stone Type

The **Stone Type** page manages the stone types available for your products: **Natural**, **Lab Grown** or **No Diamond**. Each entry has one display name for diamonds and one for gemstones, plus an image.

---

## Stone Type Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the **Search** box to find stone types. The list updates about a second after you stop typing. Clear the box to show all stone types again. |
| **Filter** | Click **Filter** to show or hide a filter box under each column heading. Filtering applies to the rows on the current page. |
| **Add Stone Type** | Click the **Add Stone Type** button to open the **Add Stone Type** drawer and create a new stone type. |
| **Edit** | Click the **Edit** icon to open the **Edit Stone Type** drawer and change a stone type's details. |
| **Delete** | Click the **Delete** icon. A box titled **Are you Sure?** asks you to confirm; click **YES** to delete the stone type or **NO** to keep it. If the deletion is not allowed, an error message is shown and the stone type stays in the list. |
| **Status** | Shows whether the stone type is **Active** or **Inactive**. |
| **Status Toggle** | Switch a stone type on or off directly from the list. The change is saved immediately, without a confirmation box. |

The **View Documentation** button at the top right of the page opens this guide.

### Stone Type List Columns

| Column | Description |
| ------ | ----------- |
| **Action** | The **Edit** and **Delete** icons. |
| **Image** | Picture of the stone type. Hover over it to see a larger preview. |
| **Diamond Name** | Name shown for diamonds of this type. |
| **Gemstone Name** | Name shown for gemstones of this type. |
| **Status** | An **Active** or **Inactive** badge, followed by the on/off switch. |

The **Stone Type** (**Natural**, **Lab Grown** or **No Diamond**) you choose in the form is not shown as a column; open **Edit** to see it. Click a column heading to sort by it. The **Action**, **Image** and **Status** columns cannot be sorted. The newest stone types are shown first, 50 rows per page by default; use the page controls under the list to move between pages or to show 25, 50, 75 or 100 rows.

:::note
This page has no **Info** button.
:::

:::note
The **Add Stone Type** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The drawer fields and the **Add Stone Type** / **Save Stone Type** button are disabled without **Edit** permission, including when you add a new stone type.
:::

### Steps to Add a New Stone Type

Click **Add Stone Type**, fill in the fields below and click **Add Stone Type** at the bottom of the drawer. When editing, the same button reads **Save Stone Type**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Diamond Name** | ✅ | Name shown for diamonds of this type, for example Lab Grown Diamond. |
| **Gemstone Name** | ✅ | Name shown for gemstones of this type, for example Lab Grown Gemstone. |
| **Stone Type** | ✅ | Choose one of the boxes: **Natural**, **Lab Grown** or **No Diamond**. |
| **Upload Image** | ✅ | Drop an image or click to upload. Accepts .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif files up to 20 MB. Recommended aspect ratio: 100 x 100. If it is missing, the message **Image is required** is shown. |

An empty text field or an unselected **Stone Type** shows **This Field is required**. A file of another type shows **Only allowed image file types can be uploaded** followed by the allowed list, and a rejected or oversized file shows **You can only upload files with a maximum size of 20 MB.** Click the **x** on the image preview to remove it; if you remove it and do not choose another, **Please Upload Image** is shown and you cannot save.

The drawer closes and the list refreshes once the stone type is saved. If saving fails, a red message appears and the drawer stays open.
