# Item Size

The **Item Size** page manages the item sizes available for your products, such as ring sizes.

---

## Item Size Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find item sizes. The list updates about one second after you stop typing; clear the box to show all item sizes again. |
| **Info** | Opens the **Item Size Info** drawer showing this module's Title and Description. Click **Submit** to save changes or **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Item Size** | Click the **Add Item Size** button to create a new item size. |
| **Edit** | Click the **Edit** icon to change an item size or its sort order. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove an item size. Click **NO** to keep it. |
| **Status** | Shows whether the item size is **Active** or **Inactive**. |
| **Status Toggle** | Switch an item size on or off directly from the list. |

The list shows the **Item Value**, **Slug**, **Sort Order** and **Status** of each record, and can be sorted and paged.

:::note
Without **Add** permission the **Add Item Size** button is disabled. Without **Edit** permission the **Edit** icon and the **Status Toggle** are disabled. Without **Delete** permission the **Delete** icon is disabled.
:::

---

### Steps to Add a New Item Size

Click **Add Item Size**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Sort Order** | - | Number that sets the display order. |
| **Item Value** | ✅ | The size value. If it is missing, the message **Item Size is required** is shown. |

:::note
The **Item Value** field and the **SUBMIT** button need **Edit** permission, even when you add a new item size.
:::
