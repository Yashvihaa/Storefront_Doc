# MM Size

The **MM Size** page manages the millimetre sizes available for your products, such as the sizes of diamonds and gemstones.

---

## MM Size Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find MM sizes. The list updates about a second after you stop typing. Clear the box to show all sizes again. |
| **Info** | Opens the **MM Size Info** drawer, which shows the module's **Title** and **Description**. Change them and click **Submit** to save, or click **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add MM Size** | Click the **Add MM Size** button to create a new size. |
| **Edit** | Click the **Edit** icon to change a size's value. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a size. Click **NO** to keep it. |
| **Status** | Shows whether the size is **Active** or **Inactive**. |
| **Status Toggle** | Switch a size on or off directly from the list. |

The list shows the **Value**, **Slug** and **Status** of each size, and can be sorted and paged.

:::note
The **Add MM Size** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The **Value** field and the **SUBMIT** button are disabled without **Edit** permission, including when you add a new size.
:::

---

### Steps to Add a New MM Size

Click **Add MM Size**, fill in the field below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Value** | ✅ | Size in millimetres, for example 3.5. Cannot start with a minus sign or contain spaces. Shows **Enter Valid MM size** otherwise. |
