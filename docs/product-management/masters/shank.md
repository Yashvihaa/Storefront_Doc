# Shank

The **Shank** page manages the shank styles used in ring products. The shank is the band of the ring.

---

## Shank Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find shanks. The list updates about a second after you stop typing. Clear the box to show all shanks again. |
| **Info** | Opens the **Shank Info** drawer, which shows the module's **Title** and **Description**. Change them and click **Submit** to save, or click **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Shank** | Click the **Add Shank** button to create a new shank. |
| **Edit** | Click the **Edit** icon to change a shank's details. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a shank. Click **NO** to keep it. |
| **Status** | Shows whether the shank is **Active** or **Inactive**. |
| **Status Toggle** | Switch a shank on or off directly from the list. |

The list shows the **Image**, **Shank Value**, **Slug**, **Sort Code** and **Status** of each shank, and can be sorted and paged.

:::note
The **Add Shank** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The drawer fields and the **SUBMIT** button are disabled without **Edit** permission, including when you add a new shank.
:::

---

### Steps to Add a New Shank

Click **Add Shank**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Shank Name** | ✅ | Name of the shank style. |
| **Sort Code** | ✅ | Short code for the shank. |
| **Upload Image** | ✅ | Drop an image or click to upload. Accepts .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .ico, .tiff and .tif files up to 20 MB. Recommended aspect ratio: 100 x 100. |
