# Tags

The **Tags** page manages the tags used to label and filter products. A tag is a short word or phrase, for example Bestseller. The **Tags** field of the Add Product form is marked as required.

---

## Tags Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the **Search** box to find tags. The list updates about a second after you stop typing. Clear the box to show all tags again. |
| **Filter** | Click **Filter** to show or hide a filter box under each column heading. Filtering applies to the rows on the current page. |
| **Info** | Opens the **Tag Info** drawer, which shows the module's **Title** and **Description**. Both are required (**This Field is required**). Change them and click **Submit** to save, or click **Cancel** to close. Without **Edit** permission the fields and **Submit** are disabled. |
| **Add Tags** | Click the **Add Tags** button to open the **Add Tag** drawer and create a new tag. |
| **Edit** | Click the **Edit** icon to open the **Edit Tag** drawer and change a tag's name. |
| **Delete** | Click the **Delete** icon. A box titled **Are you Sure?** asks you to confirm; click **YES** to delete the tag or **NO** to keep it. If the deletion is not allowed, an error message is shown and the tag stays in the list. |
| **Status** | Shows whether the tag is **Active** or **Inactive**. |
| **Status Toggle** | Switch a tag on or off directly from the list. The change is saved immediately, without a confirmation box. |

The **View Documentation** button at the top right of the page opens this guide.

### Tags List Columns

| Column | Description |
| ------ | ----------- |
| **Action** | The **Edit** and **Delete** icons. |
| **Name** | Name of the tag. |
| **Status** | An **Active** or **Inactive** badge, followed by the on/off switch. |

Click a column heading to sort by it. The **Action** and **Status** columns cannot be sorted. The newest tags are shown first, 50 rows per page by default; use the page controls under the list to move between pages or to show 25, 50, 75 or 100 rows.

:::note
The **Add Tags** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The **Tags Name** field and the **Add Tag** / **Save Tag** button are disabled without **Edit** permission, including when you add a new tag.
:::

---

### Steps to Add a New Tag

Click **Add Tags**, fill in the field below and click **Add Tag** at the bottom of the drawer. When editing, the button reads **Save Tag**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Tags Name** | ✅ | Name of the tag. If it is empty, the message **This Field is required** is shown. |

The drawer closes and the list refreshes once the tag is saved. If saving fails, a red message appears and the drawer stays open.
