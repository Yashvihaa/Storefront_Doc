# Tags

The **Tags** page manages the tags used to label and filter products. A tag is a short word or phrase, for example Bestseller.

---

## Tags Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find tags. The list updates about a second after you stop typing. Clear the box to show all tags again. |
| **Info** | Opens the **Tag Info** drawer, which shows the module's **Title** and **Description**. Change them and click **Submit** to save, or click **Cancel** to close. The Description editor is disabled without **Edit** permission. |
| **Add Tags** | Click the **Add Tags** button to create a new tag. |
| **Edit** | Click the **Edit** icon to change a tag's name. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a tag. Click **NO** to keep it. |
| **Status** | Shows whether the tag is **Active** or **Inactive**. |
| **Status Toggle** | Switch a tag on or off directly from the list. |

The list shows the **Name** and **Status** of each tag, and can be sorted and paged.

:::note
The **Add Tags** button needs **Add** permission. The **Edit** icon and the status toggle need **Edit** permission, and the **Delete** icon needs **Delete** permission. The **Tags Name** field is disabled without **Edit** permission, including when you add a new tag.
:::

---

### Steps to Add a New Tag

Click **Add Tags**, fill in the field below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Tags Name** | ✅ | Name of the tag. |
