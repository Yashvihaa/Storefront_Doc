# Stores

The **Stores** page manages your store locations. Each admin user is assigned to one of these stores on the [User Management](./user-management.md) page.

---

## Stores Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find stores. The list updates as you type; clear the box to show all stores again. |
| **Add New Store** | Click the **Add New Store** button to create a store. |
| **View** | Click the **View** icon to open the store's details in read-only mode. Click **Close** to leave. |
| **Edit** | Click the **Edit** icon to change a store's details. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a store. Click **NO** to cancel. |
| **Status Toggle** | Switch a store on or off directly from the list. |

The list shows each store's **Store Name**, **Store Code**, **City**, **Phone Number**, **Address** and status, and can be paged.

---

### Steps to Add a New Store

Click **Add New Store**, fill in the fields below and click **Submit**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Store Name** | ✅ | Name of the store. A name made only of spaces is not accepted. |
| **Store Code** | - | Short code for the store. |
| **City** | - | City where the store is located. |
| **Phone Number** | - | Store contact number. |
| **Address** | - | Full store address. |
| **Description** | - | Any extra notes about the store. |

Leading and trailing spaces are removed from every field when you save. When editing, the drawer opens with the store's saved details and the same fields.
