# Stores

The **Stores** page manages your store locations and shows how many users belong to each store.

---

## Stores Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find stores by store name, store code, city, phone number or address. |
| **Add New Store** | Click the **Add New Store** button to create a store. |
| **Edit** | Click the **Edit** icon to change a store's details. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a store. |
| **Users** | Shows how many users are assigned to the store. |

The list shows each store's **Store Name**, **Store Code**, **City**, **Phone Number**, **Address** and **Users**.

:::note
A store that still has users assigned cannot be deleted, so its **Delete** icon is not shown.
:::

---

### Steps to Add a New Store

Click **Add New Store**, fill in the fields below and click **Submit**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Store Name** | ✅ | Name of the store. |
| **Store Code** | - | Short code for the store. Saved in uppercase. |
| **City** | - | City where the store is located. |
| **Phone Number** | - | Store contact number. |
| **Address** | - | Full store address. |
