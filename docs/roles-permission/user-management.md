# User Management

The **User List** page stores the details of users who can access the admin panel. You can add users, assign each one a role, and activate or deactivate them.

---

## User List Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find users. The list updates as you type; clear the box to show all users again. |
| **Add New User** | Click the **Add New User** button to create a user. |
| **Edit** | Click the **Edit** icon to change a user's name, phone number, role or image. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a user. |
| **Status** | Shows whether the user is **Active** or **Inactive**. |
| **Status Toggle** | Switch a user on or off directly from the list. |

The list shows each user's **Role**, **Name**, **Email**, **Phone Number** and **Status**, and can be sorted and paged.

---

### Steps to Add a New User

Click **Add New User**, fill in the fields below and click **Submit**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Name** | ✅ | User's full name. |
| **Email** | ✅ | A valid email address. Used to sign in. |
| **Phone Number** | ✅ | Exactly 10 digits. |
| **Password** | ✅ | At least 8 characters, with at least one uppercase letter, one lowercase letter, one number and one special character (@ $ ! % * ? &). |
| **Confirm Password** | ✅ | Must match the password. |
| **Select Role** | ✅ | Choose one of the roles created on the [Roles](./roles.md) page. |
| **Upload Image** | - | Profile image. Recommended aspect ratio 300 x 300. |

---

### Edit a User

When editing, only **Name**, **Phone Number**, **Select Role** and **Upload Image** can be changed. **Email** and **Password** are not shown.
