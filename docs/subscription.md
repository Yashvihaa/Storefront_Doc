# Subscription & Billing

The **Subscription & Billing** page lets you manage your plan, enable jewelry configurators and buy user licences for your sales team. All charges are added to your monthly renewal.

---

## Subscription Screen List

Click a tab below the page title to switch sections. When the tabs do not fit on screen, arrow buttons appear at the ends of the tab bar.

| Tab | Description |
| --- | ----------- |
| **Overview** | Your current recurring monthly total and what is included in your plan. |
| **Configurators** | Enable more jewelry configurators for your store. |
| **Users & Licences** | Buy user licence packs and assign them to your sales team. |
| **Billing History** | Every purchase and change to your subscription. |

Click **View Documentation** at the top right to open this help page in a new browser tab.

## Pricing

| Item | Price |
| ---- | ----- |
| **Base platform fee** | $99.00 / month |
| **First configurator** | $49.00 / month |
| **Each additional configurator** | $5.00 less than the previous one, down to a minimum of $0.00 |
| **User licence pack** (2 licences) | $15.00 / month |
| **First licence pack** | Included free with the plan |

:::note
A configurator keeps the price it was enabled at. The price shown on a configurator you have not enabled is what it will cost if it is the next one you enable.
:::

## Configurators

Each configurator (Rings, Necklaces, Engagement Rings, Eternity Bands, Bracelets, Earrings, Pendants) is shown as a card with an image.

| Card State | Description |
| ---------- | ----------- |
| **Active** | Already enabled. The card has a green outline and an **Active** badge, shows the price it is locked in at (for example `Locked in at $49.00/mo`) and an **Enabled** label. |
| **Not enabled** | Shows the price if enabled next (for example `$34.00/mo if enabled next`) and a **Buy · $34.00/mo** button. |

### Steps to Enable a Configurator

1. Click **Buy** on the configurator card. The **Enable** popup opens (for example **Enable Earrings**).
2. Review the configurator, its monthly price and the **Added to monthly total** amount.
3. Choose a payment method and enter the payment details (see [Payment Details](#payment-details)).
4. Click **Pay** (for example **Pay $34.00/mo**) to enable it, or **Cancel** or the close (X) icon to close without changes.

The configurator is marked **Active**, its price is added to your monthly total and the purchase is added to **Billing History**.

## Users & Licences

### Buy User Licence Packs

Each pack grants 2 user licences for this store.

1. Use the **-** and **+** buttons to choose the number of packs (at least 1). The number of packs, the licences they add and the monthly price update as you change it.
2. Click **Buy** (for example **Buy · $30.00/mo**).
3. In the **Buy User Licence Packs** popup, review the order, choose a payment method and click **Pay**. Click **Cancel** to close without buying.

After purchase, a message lists the new licences and their 4-digit PINs. Share these PINs with your sales team. The pack count resets to 1.

### Your User Licences

Every licence you hold is listed as a card, with the total count shown at the top. The PIN is hidden (`••••`). Each card shows **Assigned to** with the user's name, email and role, or **Unassigned**. If you have no licences, the card shows **No licences purchased yet.**

| Action | Description |
| ------ | ----------- |
| **Bind** | Assign an unassigned licence to a user. Select the user from the dropdown and click **Save**, or click **Cancel**. |
| **Rebind** | Move an assigned licence to a different user. Select the user and click **Save**. |
| **Unbind** | Remove the user from the licence straight away so it can be reused. There is no confirmation popup. |
| **View Details** | Enter the licence's 4-digit PIN to see its details. |

Each user can hold only one licence, so users already assigned to another licence are not offered in the dropdown. If every user already has a licence, the card shows **All users are already bound to a licence.**

### Licence Details

Click **View Details** on a licence. The **Enter Licence PIN** popup opens with a keypad. Enter the licence's 4-digit PIN with the keypad or your keyboard; use the backspace key to correct a digit. An incorrect PIN is rejected and you can try again.

After you enter the correct PIN, the **Licence Details** popup shows:

| Field | Description |
| ----- | ----------- |
| **PIN** | The licence PIN |
| **Issued** | Date the licence was created |
| **Assigned to** | Assigned user, or **Unassigned** |
| **Email** | Assigned user's email (only when assigned) |
| **Role** | Assigned user's role (only when assigned) |

Click **Done** to close.

## Billing History

The **Billing History** card notes that your subscription renews automatically every month.

| Item | Description |
| ---- | ----------- |
| **Monthly Renewal** | Your recurring monthly charge for the base plan, configurators and licence packs. |
| **Info icon** | Opens the **Monthly Renewal Breakdown** popup, listing every item in your renewal with its date, whether it was **Included in renewal** or **Added later**, and its monthly price, followed by the **Total / month**. Close it with the X icon. |
| **History entries** | Purchases and changes made after your plan started, newest first, each with a date and the amount added per month (`--` for changes with no charge). |

If there is no history, the card shows **No billing history yet.**

## Payment Details

The purchase popups use the same payment form. Choose **CARD**, **UPI** or **NET BANKING**; **CARD** is selected each time the popup opens.

| Method | Fields |
| ------ | ------ |
| **CARD** | **CARDHOLDER NAME**, **CARD NUMBER**, **EXPIRY DATE** (MM / YY) and **CVV** |
| **UPI** | **UPI ID** (for example `yourname@bank`) |
| **NET BANKING** | **SELECT YOUR BANK**: HDFC Bank, ICICI Bank, State Bank of India, Axis Bank, Kotak Mahindra Bank or Yes Bank |
