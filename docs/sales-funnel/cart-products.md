# Cart Products

The **Cart Products** page shows the products customers have added to their shopping carts but not yet purchased. Use it to track abandoned carts and see which products customers are interested in.

---

## Cart Products Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Type in the search box to find cart products. The list updates as you type. |
| **View** | Click the **eye** icon to see the full cart item and customer details. |
| **View Documentation** | Opens the help page for this screen in a new browser tab. |

| Column | Description |
| ------ | ----------- |
| **User Name** | The customer who added the product to their cart. |
| **Product Name** | The name of the product in the cart. |
| **SKU** | The product's SKU. |
| **Price** | The product's price in the cart. |

---

### View Cart Data

Clicking the **eye** icon opens the **View Cart Data** panel.

| Section | Description |
| ------- | ----------- |
| **Product Details** | The product image, **Title** and **SKU**, plus **Size**, **Karat**, **Metal**, **Length**, **Metal Tone**, **Head Tone**, **Shank Tone**, **Band Tone**, **Gemstone**, **Engraving** and **Font Style** where they apply to the product. |
| **User Details** | The customer's **User Name**, **Email** and **Phone Number**. A dash (-) is shown for details that are not available, for example for guest shoppers. |

:::note
This page is view-only. Cart items cannot be edited or removed from the admin panel.
:::
