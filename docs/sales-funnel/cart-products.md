# Cart Products

The **Cart Products** page shows the products customers have added to their shopping carts but not yet purchased. Use it to track abandoned carts and see which products customers are interested in.

---

## Cart Products Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Type in the search box to find cart products. The list updates as you type; clear the box to show all cart products again. |
| **View** | Click the **View** icon to see the full cart item and customer details. |
| **View Documentation** | Opens the help page for this screen in a new browser tab. |

| Column | Description |
| ------ | ----------- |
| **User Name** | The customer who added the product to their cart. The list can be sorted by this column. |
| **Product Name** | The name of the product in the cart. |
| **SKU** | The product's SKU. |
| **Price** | The product's price in the cart, shown with two decimal places. |

The list can be paged at the bottom of the table.

---

### View Cart Data

Clicking the **View** icon opens the **View Cart Data** panel.

| Section | Description |
| ------- | ----------- |
| **Product Details** | The product image, **Title** and **SKU**, plus **Size**, **Karat**, **Metal**, **Length**, **Metal Tone**, **Head Tone**, **Shank Tone**, **Band Tone**, **Gemstone**, **Engraving** and **Font Style** where they apply to the product. |
| **User Details** | The customer's **User Name**, **Email** and **Phone Number**. A dash (-) is shown for details that are not available, for example for guest shoppers. |

- **Gemstone** lists each selected stone as **Stone 1**, **Stone 2** and so on, with the stone name.
- **Engraving** shows the engraving text for ring configurator products. For birthstone products it lists each **Text** and **Engraving** entry.
- If the product has no image, a placeholder image is shown.

:::note
This page is view-only. Cart items cannot be edited or removed from the admin panel.
:::
