# Wishlist Products

The **Wishlist Products** page shows the products customers have saved to their wishlists. Use it to see which products are in demand.

---

## Wishlist Products Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Type in the search box to find wishlisted products. The list updates as you type. |
| **View** | Click the **eye** icon to see the full wishlist item and customer details. |
| **View Documentation** | Opens the help page for this screen in a new browser tab. |

| Column | Description |
| ------ | ----------- |
| **User Name** | The customer who wishlisted the product. |
| **Product Name** | The name of the wishlisted product. |
| **Product SKU** | The product's SKU. |
| **Price** | The product's price. |

---

### View Wishlist Data

Clicking the **eye** icon opens the **View Wishlist Data** panel.

| Section | Description |
| ------- | ----------- |
| **Product Details** | The product image, **Title** and **SKU**, plus **Size**, **Length**, **Karat**, **Metal**, **Metal Tone**, **Head Tone**, **Shank Tone**, **Band Tone**, **Gemstone**, **Engraving** and **Font Style** where they apply to the product. |
| **User Details** | The customer's **User Name**, **Email** and **Phone Number**. A dash (-) is shown for details that are not available. |

:::note
This page is view-only. Wishlist items cannot be edited or removed from the admin panel. A wishlisted product is not a purchase; it only shows customer interest.
:::
