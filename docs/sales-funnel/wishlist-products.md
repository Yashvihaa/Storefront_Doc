# Wishlist Products

The **Wishlist Products** page (*Track products customers have saved to their wishlists*) shows the designs customers have saved but not yet bought. Use it to see which products are popular and to follow up with customers on designs they liked. The page is view-only: wishlist items cannot be edited or removed from the admin panel.

---

## Wishlist Products Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Type in the **Search** box above the table to find wishlist items. The list updates about one second after you stop typing; clear the box to show all items again. |
| **Filter** | Click **Filter** to show a filter box under each column heading. The filter narrows the rows already loaded on the current page. Click **Filter** again to hide the boxes. |
| **Sort** | Click the **Added On** heading to sort by date. The list opens with the most recently added items first. The other columns cannot be sorted. |
| **Page size** | Use the rows-per-page menu at the bottom of the table to choose 25, 50, 75 or 100 rows (50 by default), and the page arrows to move between pages. |
| **View** | Click the **View Details** (eye) icon in the **Action** column to open the item in the **View Wishlist Data** panel. |
| **View Documentation** | Opens the help page for this screen in a new browser tab. |

| Column | Description |
| ------ | ----------- |
| **Action** | The **View Details** icon. |
| **User Name** | The customer who saved the product. |
| **Product Name** | The name of the saved product. |
| **SKU** | The product's SKU. |
| **Price** | The price of one unit of the product. |
| **Added On** | The date the item was added to the wishlist. |

When there are no wishlist items, the table shows **No records to display**. If the list cannot be loaded, an error message appears briefly at the top of the screen.

---

### View Wishlist Data

Clicking the **View** icon opens the **View Wishlist Data** panel on the right of the screen. Close it with the close button in its header. While the item loads, placeholders are shown. If it cannot be loaded, the panel shows **Could not load the wishlist details**, the reason, and a **Try again** button.

Every product in the wishlist entry is shown one below the other, each with the sections below. A line is shown only when it has a value.

| Section | Details shown |
| ------- | ------------- |
| **Product Details** | The product image (a placeholder is shown if there is none), then **Title**, **SKU**, **Type**, **Quantity**, **Price**, **Metal**, **Karat**, **Size**, **Head Tone**, **Shank Tone**, **Band Tone** and **Engraving**. |
| **Diamond Details** | Shown for products with diamonds: **Stone**, **Diamond Type**, **Shape**, **Carat**, **Color**, **Clarity**, **Cut**, **Side Diamond Type**, **Side Color**, **Side Clarity** and **Side Cut**. |
| **Price Breakdown** | How the price was built up: **Metal Value**, **Labour Charge**, **Other Charge**, **Center Diamond**, **Side Diamond**, **Margin** (amount and rate), **Price Correction** (before and after, when a price correction was applied) and **Final Price**. |
| **User Details** | **User Name**, **Email**, **Phone Number**, **Items** (number of items) and **Added On**. A dash (-) is shown for details that are not available. |

:::tip
To download every customer's wishlist as an Excel file, use the **Customers Wishlist** report on the [Customer Reports](../customer-management/customer-reports.md) page.
:::
