# Price Display

The **Price Display** page controls whether customers see prices while building a custom design, and which price they see. It applies to the product configurator (Diamond Setup, Metal Setup and Congregator steps) and does not affect prices shown to you in the admin panel.

---

## Configurator Pricing

Three options are listed, each with its own switch. Exactly one option is active at a time.

| Option | Description |
| ------ | ----------- |
| **Price Display [TCCTECH price + Margins]** | Customers see TCCTECH's benchmark price plus your configured margins. This is the default. |
| **Price Display [Own pricing + Margins]** | Customers see your own store pricing plus your configured margins. |
| **No Pricing Display** | Prices are hidden from customers throughout the configurator. Use this if quotes are handled separately, for example in-store or by a sales rep. |

A short description of the active option is shown below the list.

---

## Changing the Setting

1. Click an option, or turn on its switch.
2. The change is saved immediately and a **Saved** confirmation appears. There is no separate Save button.

:::note
Clicking the option that is already active does nothing. To change the setting, select a different option.
:::
