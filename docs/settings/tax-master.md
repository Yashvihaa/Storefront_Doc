# Tax Master

**Tax Master** lets you configure the tax rates used by checkout and order calculations. Each tax has a name and a percentage rate, and can be switched on or off at any time.

---

## Tax Master Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find taxes. The list updates as you type; clear the box to show all taxes again. |
| **Add Tax** | Click the **Add Tax** button to create a new tax. |
| **Edit** | Click the **Edit** icon to change a tax's name or rate. |
| **Delete** | Click the **Delete** icon and confirm with **YES** to remove a tax. |
| **Status** | Shows whether the tax is **Active** or **Inactive**. |
| **Status Toggle** | Switch a tax on or off directly from the list. |

The list shows the **Name**, **Rate (%)** and **Status** of each tax, and can be sorted and paged.

:::note
**Add Tax** is disabled for users without **Add** permission. The **Edit** icon and the **Status Toggle** are disabled without **Edit** permission, and the **Delete** icon is disabled without **Delete** permission.
:::

---

### Steps to Add a New Tax

Click **Add Tax**, fill in the fields below and click **SUBMIT**. When editing, the button reads **EDIT**. Click **Cancel** to close without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Tax name** | ✅ | Name used to identify the tax, for example GST, IGST or VAT. |
| **Rate (%)** | ✅ | Tax percentage. Must be a number from 0 to 100. For example, 18 means 18% tax. |

When editing, the drawer opens with the tax's saved name and rate.
