# Ring Size

The **Ring Size Management** page (titled **Item Size Management** on screen) lets you choose which regional ring size standards your store uses, and shows a chart of equivalent sizes across all supported regions.

---

## Select Country

Under **Select Country**, tick one or more cards to choose the ring size standards. You can select several at once. A selected card is highlighted.

| Option | Sizing Scale |
| ------ | ------------ |
| **US, Canada, Mexico** | Numerical scale from 0 to 13.5, including quarter and half sizes. Most common for North American operations. |
| **France** | Metric inner circumference in millimeters (for example, 44 to 70). Standardized across the EU and international shipping. |
| **Germany, Russia, Ukraine, Asia** | Numerical scale from 1 to 27 based on inner diameter measurements. |
| **India, China, Japan, South America, Turkey, Israel** | Numerical scale from 1 to 27 based on inner diameter measurements. |
| **Italy, Spain, Netherlands, Switzerland** | Metric inner circumference in millimeters (for example, 44 to 70). Standardized across the EU and international shipping. |
| **UK, Australia, Ireland, New Zealand, South Africa** | Alphabetical scale from A to Z+ (for example, L, M, N). Used widely in Commonwealth countries. |

Your choice is not saved until you click **Save** at the top right of the **Select Country** section.

| Rule | Description |
| ---- | ----------- |
| **Save** | Becomes active only after you change the selection, and only while at least one country is ticked. After a successful save, the message "Ring size countries updated successfully" appears. |
| Permission | Without **Edit** permission the cards, checkboxes and **Save** button are disabled. |

:::note
You cannot save with no country ticked. If you untick every card, **Save** stays disabled.
:::

---

## Ring Size Chart

The **Ring Size Chart** below the cards lists each ring size with its equivalent in every region, one column per region. The chart always shows all six regions, whichever cards you ticked. A **-** in a cell means there is no equivalent size in that region. The chart is for reference only and cannot be edited on this page. While it loads, the chart shows **Loading...**; if no sizes are available, it shows **Data Not Available**.
