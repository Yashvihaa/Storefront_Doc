# Ring Size

The **Ring Size Management** page lets you choose which regional ring size standard your store uses, and shows a chart of equivalent sizes across all supported regions.

---

## Select Country

Under **Select Country**, click one of the cards to choose the ring size standard. The selected card is highlighted and the change is saved immediately; a confirmation message appears. There is no separate save button.

| Option | Sizing Scale |
| ------ | ------------ |
| **US, Canada, Mexico** | Numerical scale from 0 to 13.5, including quarter and half sizes. |
| **France** | Metric inner circumference in millimeters (for example, 44 to 70). |
| **Germany, Russia, Ukraine, Asia** | Numerical scale from 1 to 27 based on inner diameter. |
| **India, China, Japan, South America, Turkey, Israel** | Numerical scale from 1 to 27 based on inner diameter. |
| **Italy, Spain, Netherlands, Switzerland** | Metric inner circumference in millimeters (for example, 44 to 70). |
| **UK, Australia, Ireland, New Zealand, South Africa** | Alphabetical scale from A to Z+ (for example, L, M, N). |

If no standard has been saved yet, **US, Canada, Mexico** is selected by default.

---

## Ring Size Chart

The **Ring Size Chart** below the cards lists each ring size with its equivalent in every region, one column per region. The chart is for reference only and cannot be edited on this page. If no sizes are available, the chart shows **Data Not Available**.
