# Duty and Tariff

The **Duty & Tariff Management** module lets you set up tariff rules, such as import duties or customs charges, and choose the product types they apply to.

---

## Duty & Tariff Screen List

| Action | Description |
| ------ | ----------- |
| **Search** | Use the search box to find tariff rules. The list updates as you type. |
| **Add Tariff Rule** | Click the **Add Tariff Rule** button to open the popup for a new rule. |
| **Edit** | Click the **Edit** icon to change an existing rule. |
| **Delete** | Click the **Delete** icon to remove a rule. Click **YES** in the confirmation popup to delete it, or **NO** to cancel. |
| **Status** | Use the toggle switch to activate or deactivate the rule. |

The list shows the following columns:

| Column | Description |
| ------ | ----------- |
| **Rule Name** | Name of the tariff rule. |
| **Type** | Margin type used by the rule. |
| **Value** | Tariff value set on the rule. |

---

### Steps to Add a New Tariff Rule

Click **Add Tariff Rule**. The **Add New Tariff Rule** popup opens. Fill in the fields and click **Save** (or **Edit** when changing an existing rule). Click **Cancel** to close the popup without saving.

| Field | Required | Remarks |
| ----- | -------- | ------- |
| Tariff Name | ✅ | Enter a name that identifies the rule in the list. |
| Select Margin Type | ✅ | Choose **Percentage (%)**. |
| Value | ✅ | Enter a value greater than 0, with up to 2 decimal places. |
| Product Type | ✅ | Select one or more product types: Dynamic Product, Variant single product, Birthstone configurator, Ring Configurator, Three Stone Configurator, Eternity Band Configurator, Bracelet Configurator, Stud Configurator or Pendant Configurator. |
