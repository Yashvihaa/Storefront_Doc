# Gift Charges

The **Gift Charges** page sets an extra charge for each cart product the customer marks for gift packaging. You can charge a percentage of the product price or a fixed amount, or keep gift packaging free.

---

## Gift Charge Settings

| Setting | Description |
| ------- | ----------- |
| **Gift Chargeable Provision** | Switch on to charge for gift packaging. When off, gift packaging is free for customers and the other settings are disabled. Off by default. |
| **Charge Type** | Choose **Percentage (%)** to charge a percentage of each gifted product's price, or **Fixed Amount ($)** to charge the same flat amount for each gifted product. |
| **Charge Percentage / Charge Amount** | The charge value. The label changes with the charge type. |
| **Example** | A preview line showing the gift charge and total the customer would pay for a sample product price. It updates as you change the settings. |

---

### Field Rules

| Field | Required | Remarks |
| ----- | -------- | ------- |
| **Gift Chargeable Provision** | - | On or off. |
| **Charge Type** | ✅ | **Percentage (%)** or **Fixed Amount ($)**. |
| **Charge Percentage** | ✅ | Shown for **Percentage (%)**. Must be between 0 and 100. |
| **Charge Amount** | ✅ | Shown for **Fixed Amount ($)**. Must be 0 or more. |

The charge value is required only while **Gift Chargeable Provision** is on.

---

## Saving Changes

- The **Save** button becomes active once you change any setting. Click it to apply the changes; a confirmation message appears.
- Click **Cancel** (shown only when there are unsaved changes) to discard them and return to the saved settings.
